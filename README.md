# Personal-Portfolio

A responsive personal portfolio website showcasing 6 projects, an about section, and a contact form. Built mobile-first and deployed with GitHub Pages.

## 🌐 Live Demo
[View Portfolio](https://Stephen9883002.github.io/Personal-Portfolio) 

## ✨ Features
- **6 Projects Showcase**: Cards with project links and descriptions
- **About Section**: Brief intro about you
- **Contact Form**: For people to reach you
- **Mobile-First Design**: Looks good on phone, tablet, desktop
- **Deployed with GitHub Pages**: Free hosting

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
